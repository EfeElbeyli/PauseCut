# 🎬 PauseCut

> AI-assisted video trimming and smart editing workspace

PauseCut is a modern AI-powered video editing tool that automatically detects silence, repetition, and low-value segments to help refine long videos into clean, watchable content.

---

## ⚡ Features

- 🎧 Silence detection
- 🔁 Repetition detection
- ✂️ Automatic segment generation
- 🎞 Timeline-based editing UI
- 👥 Character-based filtering
- ⚡ Fast preview rendering
- 🎯 Smart editing modes

---

## 🧠 How it works

1. Paste a video link
2. PauseCut analyzes the video
3. Segments are generated automatically
4. You review and edit
5. Export the final result

---

## ⚙️ Tech Stack

- Frontend: Next.js
- Backend: FastAPI
- Rendering: FFmpeg
